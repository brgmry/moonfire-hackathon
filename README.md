# moonfire-hackathon

Moonfire Build Night Hackathon, Thu 22 Oct 2026. Team: Bergen (frontend, pitch), Allen (orchestrator, agent loop), Akshay (sandboxes, environments). Interface contract: [docs/contract.md](docs/contract.md).

## Our choice: Sparkles Cloud Crew Track (always-on-agents)

## Tracks

### Cambridge Compute Co. Autoresearch Track
Think AI systems that can autonomously propose ideas, run experiments, evaluate results, and iteratively discover better solutions.
You'll have just three hours to turn an idea into something compelling.

### Sparkles Cloud Crew Track (always-on-agents)
Think AI agents working as a crew in cloud sandboxes, splitting up one goal, reviewing each other's work, and delivering a concrete result.
One goal. Your crew. A working result.

### White Circle On-Device AI Track (agent security)
Think fine-tuning a small AI model to do one useful task exceptionally well, then running it entirely on your laptop so no data ever leaves the device.
The best project won't have the smartest model, it'll have the cleverest use for a small one.
