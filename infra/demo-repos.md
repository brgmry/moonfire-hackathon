## Rejected (for reference)
- `antfu/vitesse-lite`: HEAD needs pnpm 12 and a modern Vite. Older sha `fb8b15e` (Vite 5, pnpm 9.9) crashed during `pnpm install` locally ("readStream must be readable", pnpm 9 on Node 24). It's also 677 packages. Too fragile.
- `ConorSheehan1/spelling-bee`: Vite 2 + yarn.lock, 2 human authors.
- `zaydek/heroicons.dev`: 3,799 files (SVGs).
- json-server HEAD: `engines.node >=22.12`.

## Container risks seen
- **Node version.** `python:3.12-slim` now tracks Debian **trixie**, whose apt `nodejs` is **20.x**, not 18 (bookworm was 18.19). Both json-server beta.3 and Vite 4 work on 18 and 20. Anything on Node 22+ (json-server HEAD, Vite 7+) will not.
- **pnpm.** `npm i -g pnpm` installs pnpm 11 today, which may refuse old Node. None of the picks need pnpm. Pin `pnpm@9` in the image if pnpm is kept.
- **Shallow history.** Depth 50 hides older authors (json-server shows 1). If the leaderboard matters for a repo, clone it deeper.

**Live:** run **python-slugify first** (fastest, tests green in seconds), then **json-server @ beta.3** (API and the honest README gap at L130/L135), then **vite-deploy** (web). **humanize** is the backup.
